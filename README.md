# abdikarim.cloud

Abdikarim's Azure architecture and cloud engineering portfolio. The site is a React + TypeScript app built with Vite.

## Run locally

```bash
npm install
npm run dev
```

## Add a project

Add a new entry to `src/data/projects.ts`. The project registry automatically switches from the current build-in-progress state to responsive case-study cards when the array contains projects.

## Production checks

```bash
npm run lint
npm run build
```
